# Toolchain tests

This separate Bazel workspace helps contributors validate toolchain
configuration and behavior. It isn't a complete platform development example.

See [Test and validate toolchains](../docs/contributors/tests_and_validation.md)
for prerequisites, native and cross-target checks, QNX emulation, and EBcLfSA
high-integrity tests. See the [test suite reference](../docs/contributors/test_suite.md)
for individual tests.
